# 시장자료 주간 갱신 (매주 목요일)

매출분석도구의 «목표·추이 > 건설동향 / 방화문시장 분석 / 철강시세 전망» 세 화면은
`market_feed.json` 을 받아 화면 자료를 덮어쓴다(index.html 의 `script#v1540-market-feed`).
주간 갱신은 **market_feed.json 만** 고쳐 올린다. index.html·APP_BUILD 는 건드리지 않는다.

## 파일 형식

```json
{ "tag": "YYYY-MM-DD", "asOf": "YYYY-MM-DD", "note": "...",
  "hkeys": { "history": "YYYY-MM-DD|", "stHistory": "YYYY-MM-DD|" },
  "update": { "항목": "값", ... } }
```

- `tag` 는 이전보다 커야 화면이 받는다. 같은 날 다시 고치면 `2026-11-26b` 처럼 끝에 영문 소문자 한 자.
- `update` 에 넣은 항목만 바뀌고, 빠진 항목은 화면에 남아 있는 이전 값을 그대로 쓴다.
  지난 주 파일의 항목은 그대로 두고, 새 자료가 있는 항목만 값을 고친다.
- 표 항목은 줄마다 `|` 로 칸을 나눈다. **칸 수를 바꾸지 않는다**(검사 도구가 막음). 줄 추가·삭제는 가능.
- 추세 칸은 `상승`·`하락`·`보합` 중 하나만 쓴다(다른 말은 화면에서 «보합»으로 보임).
- `history`·`stHistory` 는 맨 앞에 `날짜|내용` 한 줄만 넣는다(이전 줄은 화면이 알아서 이어 붙임).
- 화면 문구는 개조식(«~함·~임·~음»), «습니다·입니다» 쓰지 않음. 강조는 `<b>…</b>` 만.

## 고칠 자료(공표·보도된 숫자만, 기준일을 같이 적음)

철강시세(st…):
- 열연 국산정품·수입재 유통가, 철근 SD400 유통가 — 철강금속신문(snmnews.com) 주간시장동향·[열연강판]·[철근]
- 철광석·원료탄 — [주간 철강원료 동향] / [주간원료동향]
- LME 아연·니켈·알루미늄·전기동 현물/3개월 — [일일비철시황]
- 원/달러 종가 — 목요일 전날 서울 외환시장 종가
- 철스크랩 등급별·제강사 인하 차수·적용일, 터키 수입 스크랩 — 국내 철스크랩價 주간 기사
- 중국 내수 가격(스틸홈 주평균), 반덤핑·통상 일정(무역위원회·재정경제부)
- 냉연·GI·PO·EGI·후판·STS 국내 유통가는 공개 숫자를 찾았을 때만 바꾸고, 못 찾으면 이전 값·기준일 유지

건설동향·방화문(asOf·verify·summary·checkTbl·trend·fdNews·history·srcline 등):
- 국토교통부 월간 주택통계(매월 말 공표: 인허가·착공·분양·준공·미분양)
- 국가데이터처 산업활동동향(매월 말: 건설기성·건설수주)
- 한국건설산업연구원 건설경기실사지수(매월 초), 건설·부동산 전망, 건설공사비지수
- 방화문·건축자재 제도 변경(국토교통부 고시·입법예고, 품질인정)

규칙:
- 날짜가 지난 7~10일 안인 기사·공표자료만 새 값으로 쓴다. 숫자는 원문에서 확인한 것만.
- 확인 못한 값은 바꾸지 말고 `stVerify`/`verify` 에 «미확인·이전 값 유지»로 적는다.
- 2027·2028 전망 칸은 기관 전망이 있으면 그 값, 없으면 이전 값을 유지(자체 추정은 «자체 추정» 표시).

## 순서

1. `git pull` 최신 main.
2. `cp market_feed.json /tmp/prev_feed.json`
3. 자료 조사 후 `market_feed.json` 수정(tag·asOf·stAsOf·hkeys 날짜를 이번 주 목요일로).
4. `node tools/market_feed_check.js market_feed.json /tmp/prev_feed.json` → «✓ 검사 통과» 일 때만 다음 단계.
5. 커밋 메시지 «시장자료 주간 갱신 YYYY-MM-DD — 철강·건설 주요 변동 한 줄», main 에 push.
6. 결과 요약: 바뀐 숫자(이전→이번)·못 찾은 항목·출처 목록.
